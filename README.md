# Score Clipper

커버 영상(드럼·기타·베이스 등) 하단에 4마디씩 표시되는 악보를 자동으로 잘라내
전체 악보 한 장(PNG/PDF)으로 이어붙인다.

## 동작 원리

1. 영상을 일정 간격(기본 0.5초)으로 샘플링해 악보 띠 영역만 크롭
2. 연속 프레임 간 이미지 차이로 페이지 넘김 순간 감지
3. 페이지별 안정 구간의 중간 프레임을 대표로 선택
4. 반복 구절 보존: 중복 비교는 직전 페이지와만 한다
   (전체 비교하면 마디 번호만 다른 반복 구절이 삭제되는 버그 - 실제로 겪음)
5. 세로로 이어붙여 출력

제약: 페이지 넘김 방식 전용. 연속 스크롤 악보는 미지원.

## 웹앱 (web/index.html)

- 서버 없는 정적 페이지. 영상은 브라우저 밖으로 전송되지 않음
- 사용법: 영상 파일 업로드 -> 악보 영역 드래그 지정 -> 추출 -> PNG 다운로드 / 인쇄(PDF)
- 유튜브 URL 직접 입력은 미지원 (브라우저 보안 제약). yt-dlp 등으로 파일 저장 후 업로드
- 로컬 실행: `python3 -m http.server 8765 -d web` 후 http://localhost:8765
- 테스트 훅: `?src=파일URL` 쿼리로 자동 로드 (같은 출처 파일)

## CLI (score_stitch.py)

유튜브 URL부터 한 번에 처리할 때 사용 (yt-dlp + ffmpeg 필요).

```
yt-dlp --no-playlist -f "bv*[height<=1080][ext=mp4]" -o video.mp4 "<URL>"
pip install -r requirements.txt
python score_stitch.py video.mp4 --y 940 --height 140 --fps 2 --out score_out
```

`--y`, `--height`는 악보 띠의 시작 y좌표와 높이(px). 프레임 하나 뽑아서 확인 후 지정.
